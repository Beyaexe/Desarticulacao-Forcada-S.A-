# 🤖 Desarticulação Forçada S/A

> **Cargo:** Analista de Desarticulação Sênior  
> **Missão:** Testar o limite físico e a resistência dos bonecos de testes (*ragdolls*) da corporação utilizando um canhão de alta potência. Tudo em nome da ciência (e do controle de qualidade, claro).

O projeto é um jogo focado em física, caos e destruição controlada, desenvolvido de forma independente para fins de portfólio e estudo de mecânicas na Unity.

---

## 🎮 O Jogo

Em **Desarticulação Forçada S/A**, você não está destruindo propriedades por diversão — este é o seu trabalho. Como Analista Sênior, você deve operar a artilharia da empresa, ajustar a potência e disparar contra os novos protótipos de ragdolls para garantir que eles quebrem exatamente onde deveriam.

### ✨ Funcionalidades Principais
* **Física de Ragdoll Avançada:** Reações realistas e desmembramentos baseados na força do impacto.
* **Sistema de Canhão Ajustável:** Controle de mira e carga de tiro para máxima eficiência.
* **Sistema de Pontuação:** Avaliação de danos estruturais baseada nas articulações removidas.

---

## 🛠️ Desenvolvimento & Tecnologias

O projeto foi construído do zero seguindo boas práticas de arquitetura e controle de versão.

* **Engine:** Unity (Versão 2022.3 LTS ou superior)
* **Linguagem:** C#
* **Render Pipeline:** Universal Render Pipeline (URP 2D)
* **Principais Sistemas:** Unity Input System (Novo sistema de inputs), Physics 2D.

## 🚀 Como Executar o Jogo

### 📦 Opção 1: Jogando a Versão Compilada (Recomendado)
*Assim que o jogo estiver finalizado, os links de download estarão disponíveis aqui.*
1. Baixe o arquivo `.zip` da versão mais recente na seção [Releases](https://github.com) do GitHub.
2. Extraia os arquivos em uma pasta de sua preferência.
3. Dê um duplo clique no arquivo `DesarticulacaoForcadaSA.exe` para iniciar o jogo.

### 💻 Opção 2: Executando o Código Fonte (Para Desenvolvedores)
Se você deseja abrir o projeto dentro do editor da Unity:
1. Certifique-se de ter o **Git LFS** instalado em sua máquina.
2. Clone este repositório:
   ```bash
   https://github.com/Beyaexe/Desarticulacao-Forcada-S.A-.git
   ```
3. Abra o **Unity Hub** e clique em **Add > From disk**.
4. Selecione a pasta raiz do projeto e abra com a versão correspondente da Unity.
